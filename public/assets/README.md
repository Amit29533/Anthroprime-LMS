# AnthroPrime brand assets

The AP logo and the Latin DM Sans / Cormorant Garamond font files were obtained from the public assets of https://anthroprime.com on 27 October 2026, to match that site's identity at the repository owner's request.

The fonts are hosted locally so rendering does not depend on a third-party font service. The accompanying SIL Open Font License files are retained in `fonts/`, sourced from the corresponding Google Fonts repositories. The logo remains AnthroPrime's brand asset.

`public/theme.css` mirrors the website's light/dark palette. `public/brand.css` adapts that identity to the LMS navigation, lessons, courses and authoring screens.
